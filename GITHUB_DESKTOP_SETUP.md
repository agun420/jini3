# GitHub Desktop setup

This folder is already initialized as an uncommitted Git repository on the `main` branch. No author identity or commit history has been imposed, so the first commit uses your own GitHub Desktop identity.

1. Extract the ZIP.
2. In GitHub Desktop, choose **File → Add local repository**.
3. Select `Project-Daybreak-Dashboard`.
4. Review all files under **Changes**.
5. Use a summary such as `Publish Daybreak Command Center`.
6. Select **Commit to main**.
7. Select **Publish repository**.
8. On GitHub, choose **Settings → Pages → GitHub Actions**.
9. Run **Actions → Deploy Daybreak Dashboard** once.

The repository contains public-safe demonstration data only. GitHub Pages is public; never commit a private snapshot, API key, account number, exact balance, or live position.
