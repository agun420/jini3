# Publish with GitHub Desktop

This folder is already initialized as an **uncommitted Git repository** on the `main` branch. No author identity or commit history has been imposed, so the first commit will use your own GitHub Desktop identity.

1. Extract the ZIP archive.
2. Open GitHub Desktop.
3. Choose **File → Add local repository**.
4. Select the extracted `Project-Daybreak` folder.
5. Review the files shown under **Changes**.
6. Enter a summary such as `Initial Project Daybreak v1.0.2 hardened release`.
7. Click **Commit to main**.
8. Click **Publish repository**.
9. Keep the repository private initially because this is automated trading infrastructure.

Do not commit real credentials. Copy the example configuration files and provide secrets through environment variables or your deployment secret store.
