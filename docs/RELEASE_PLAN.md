# Project Daybreak Release Plan

## v1.0.2 — Hardened paper production candidate

The v1.0.2 software release is complete when the repository, wheel, schemas, migrations, fixtures, test suite, release evidence models, deterministic review engine, security gates, dependency audit, and isolated wheel smoke test pass offline verification.

External paper qualification is a separate evidence milestone. It requires target-VM sessions, real paper fills, replay proof, backup/restore, failure drills, online service acceptance, and human approvals bound to the final artifact manifest.

Live-money enablement is outside v1.0.2 and cannot be granted by the software itself. The target campaign must use a dedicated Alpaca paper account and must demonstrate stale-fencing-token rejection at every downstream write boundary.
